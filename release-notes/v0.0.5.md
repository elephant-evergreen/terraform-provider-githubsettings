## Highlights

- Refreshes can read up to four GitHub settings at once per provider configuration. Reads still fetch current values from GitHub. Writes remain exclusive and spaced at least one second apart.
- Queued requests stop when GitHub reports a rate limit. If several in-flight requests report different reset times, the provider honors the longest cooldown.
