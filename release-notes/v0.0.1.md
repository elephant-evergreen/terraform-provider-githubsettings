## Upgrade notes

This is the initial Registry release. To adopt settings on an existing repository or organization, import them and review a plan before applying. Keep each setting under one provider. See the [quickstart](https://github.com/elephant-evergreen/terraform-provider-githubsettings/blob/v0.0.1/README.md#quickstart).

## Highlights

- Manage nine settings across Actions and OIDC, pull requests, immutable releases, secret scanning, and organization deploy keys.
- Record three settings without writing to GitHub: archived-repository settings, repository secret-scanning validity checks, and selected organization defaults and member permissions.
- Remove a resource from Terraform management while preserving the GitHub setting.
- Send GitHub API requests serially and report when GitHub asks the user to retry later.

## Compatibility

The packages target macOS and Linux on amd64 and arm64. Tests use Terraform 1.17.1 and synthetic GitHub REST API responses. The provider targets GitHub.com and uses the 2026-03-10 REST API. API access depends on the permissions and availability of each GitHub setting. See the [resource reference](https://registry.terraform.io/providers/elephant-evergreen/githubsettings/0.0.1/docs).
