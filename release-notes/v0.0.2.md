## Upgrade notes

Existing configurations and state need no changes. If you are still moving from the bundled OpenTofu provider, follow the [updated migration guide](https://github.com/elephant-evergreen/terraform-provider-githubsettings/blob/v0.0.2/docs/guides/bundled-provider-migration.md#switch-the-remaining-resources).

## Fixes

- The migration guide now tells you to change the provider address from the working copy that still has the bundled provider installed. This avoids initialization looking for the bundled provider in a registry while its address is still in state.

[Compare v0.0.1 with v0.0.2](https://github.com/elephant-evergreen/terraform-provider-githubsettings/compare/v0.0.1...v0.0.2)
